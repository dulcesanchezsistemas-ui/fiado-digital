# Proyecto: Fiado Digital

## Objetivo
App web para tiendas de barrio en Guatemala que digitaliza el cuaderno de
"fiado" (ventas a crédito): el dueño fotografía la página y la IA extrae
nombres, montos y fechas.

## Stack
- Backend: Node.js + Express
- Base de datos: PostgreSQL
- Frontend: HTML/CSS/JS simple (o React si es necesario)
- Contenedores: Docker + docker-compose
- Proxy: Nginx con HTTPS
- Despliegue: VPS Ubuntu, CI/CD con GitHub Actions
